# Partner-Portal
Partner Portal and Configurator
This was created with claude code in VS code. 
The portal is for partner users to see all their transactional  and subscription data with a company
The transactional data can be updated via CSV or integration with a ERP
It shows key metrics and dashboards for the partner business dev users
It also has a configurator to configure and price the products
The configurator data, SKUs and rules can be specified via an excel/rules skills file
