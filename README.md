# Partner Portal

A partner-facing business portal designed for viewing subscription data, transaction history, revenue health, and configurable product offerings in a single dashboard experience.

## What this project demonstrates

- Partner performance and sales overview
- Transaction and subscription visibility
- Pricing and product configurator flow
- Dashboard-first design for business users
- Data-driven product workflows for sales teams

## Tech stack

- HTML
- CSS
- JavaScript
- CSV-backed data model

## Run locally

```bash
cd partner-portal
python3 -m http.server 8000
```

Then open: http://localhost:8000

## Project files

- `index.html` — main portal shell
- `app.js` — business logic, rendering, and configurator behavior
- `data/` — transaction and product data files
- `n8n_workflow_1_get_invoices.json` — workflow example
- `n8n_workflow_2_overdue_notifications.json` — notification automation example
